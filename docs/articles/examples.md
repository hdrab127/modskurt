# Examples

Eventual case studies using `msktr` in different settings:

- \[ \] [Continuous data](#): Modelling biomass with the zero-augmented
  Gamma distribution.
- \[ \] [Proportional data](#): Modelling % cover with the tail-adjusted
  Beta distribution.
- \[ \] [Random effects](#): Allowing for hierarchical structure such as
  different local populations.
- \[ \] [Temporal effects](#): Allowing for hierarchical structure such
  as change over time.
- \[ \] [Multiple gradients](#): Building a picture of the empirical
  realised niche with multiple environmental gradients.
- \[ \] [Multiple species](#): Comparing community responses to an
  environmental gradient.

Have an idea for another? Post it at
<https://github.com/hdrab127/modskurt/issues>.
