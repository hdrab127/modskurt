# The Negative Binomial Probability Mass Function (alternative parameterisation)

The Negative Binomial Probability Mass Function (alternative
parameterisation)

## Usage

``` r
dnbinom2(x, mu, kappa, log = FALSE)
```

## Arguments

- x:

  vector of (non-negative integer) quantiles

- mu:

  mean

- kappa:

  dispersion (inverse square root size)

- log:

  logical; if TRUE, probabilities p are given as log(p)

## Value

the (log) probability mass at x, given mu and kappa
