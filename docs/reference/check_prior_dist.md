# Check prior distribution statistics for potential misspecification clues

Check prior distribution statistics for potential misspecification clues

## Usage

``` r
check_prior_dist(spec, use_subset = TRUE, n_draws = 50)
```

## Arguments

- spec:

  the modskurt model specification returned by \`mskt_spec\`

- use_subset:

  whether to use specified subset or all data

- n_draws:

  number of draws from the joint prior to use
