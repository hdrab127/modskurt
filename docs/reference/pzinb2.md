# Zero-inflated Negative Binomial Distribution Function

Zero-inflated Negative Binomial Distribution Function

## Usage

``` r
pzinb2(q, mu, kap, zi)
```

## Arguments

- q:

  vector of quantiles

- mu:

  mean of the distribution

- kap:

  dispersion (inverse square root size)

- zi:

  vector of (in \\\[0, 1\]\\) zero-inflation parameters
