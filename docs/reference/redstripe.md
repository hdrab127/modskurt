# \*Sebastes proriger\* (redstripe rockfish) abundance

Discrete counts of \*sebastes proriger\* along the Pacific Northwest
continental slope and shelf

## Usage

``` r
data(redstripe)
```

## Format

An object of class `tbl_df` (inherits from `tbl`, `data.frame`) with
2330 rows and 8 columns.

\<https://www.fisheries.noaa.gov/west-coast/science-data/us-west-coast-groundfish-bottom-trawl-survey\>
