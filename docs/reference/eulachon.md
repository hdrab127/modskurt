# \*Thaleichthys pacificus\* (eulachon) abundance

Discrete counts of \*thaleichthys pacificus\* along the Pacific
Northwest continental slope and shelf

## Usage

``` r
data(eulachon)
```

## Format

An object of class `tbl_df` (inherits from `tbl`, `data.frame`) with
2430 rows and 8 columns.

\<https://www.fisheries.noaa.gov/west-coast/science-data/us-west-coast-groundfish-bottom-trawl-survey\>
