# Log-Modskurt (mskt) unimodal mean function

Log-Modskurt (mskt) unimodal mean function

## Usage

``` r
mskt(x, H, m, s, r = 0.5, d = 0, p = 1)
```

## Arguments

- x:

  predictor variable (real number vector)

- H:

  height of curve at mode (real number \> 0)

- m:

  mode (real number)

- s:

  scale (real number \> 0)

- r:

  asymmetry (real number in (0, 1))

- d:

  flatness (real number \>= 0)

- p:

  tail exaggeration (real number in (0, 2))

## Value

vector of log-scale mean values (real number vector)
